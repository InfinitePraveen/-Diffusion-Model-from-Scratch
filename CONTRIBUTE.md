# Contributing

Thanks for taking an interest in this project.

## Local setup

1. Fork the repository.
2. Create a virtual environment.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run the notebook or start Django with `python manage.py runserver`.

## Good contributions

- Improve the explanation of DDPM concepts.
- Add CPU-friendly experiments.
- Improve the Django interface without adding unnecessary dependencies.
- Fix notebook bugs or improve reproducibility.
- Add tests for the Django demo.

Please keep the repository simple. Avoid adding a `src/` directory, heavyweight datasets, generated model files, or unnecessary preprocessing modules.
